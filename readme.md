# Plugin Grandma 3 Color FX
![Photo](https://images2.imgbox.com/24/07/2FTqH7Ks_o.png)

## How to use
Prérequis : avoir des presets de couleurs, comme avec un color picker

1. Importer et lancer le plugin dans Grandma 3
2. Sélectionnez les groupes en les entrant dans le champ, les formats acceptés sont : soit un par un, soit 1 + 2 + 3... soit 1 Thru 3 (ou thru) une fois fini, laissez done puis appuyez sur entrer
3. Sélectionnez les presets de couleurs de la même manière que vous voulez dans votre petit color picker du color FX
4. Entrez le numéro de layout que vous voulez utiliser 
5. Entrez le numéro de la première macro

Et voilà !

## Les bugs connues 
- Les formes ne fonctionnent pas
- Les macros ne sont pas toutes à côté de là où on a entré le premier numéro
- Le plugin crée étape par étape plutôt que tout à la fin
